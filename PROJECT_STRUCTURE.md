## Key Rules

**`src/` is for reusable logic only.**
Scripts in `scripts/` call functions from `src/`. Logic does not live inside scripts directly.

**`notebooks/` is for exploration only.**
Do not train final models in notebooks. Use them to visualize and understand data.

**`configs/` is the single source of truth for hyperparameters.**
If a number appears in `src/` that is not from config, it is a bug.

**`data/` and `checkpoints/` are not committed.**
Add both to `.gitignore`. Use `reports/dataset_summary.md` to document data stats instead.

**`results/` is committed.**
All CSV files and figures go here and are tracked in Git.
